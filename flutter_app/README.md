# SmartAlarm — application Flutter

Application de contrôle de l'alarme (Flutter Web en priorité, Android possible).
Voir la documentation du projet : [../docs/setup.md](../docs/setup.md#application-flutter).

```bash
cp config/dart_defines.example.json config/dart_defines.json   # puis renseigner les valeurs
flutter run -d chrome --dart-define-from-file=config/dart_defines.json
```
